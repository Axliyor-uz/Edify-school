# Edify manager UI kit

Import everything from `@/components/manager-ui`. The switchboard driving the
whole kit is **/design.manager.config.ts** — change one word there to re-skin
the entire manager panel (palette, dark mode, shapes, density, fonts, motion,
component styles, shell navigation).

- Tokens live in `./theme.css`, imported once by `app/manager/layout.tsx`;
  palettes are generated by `scripts/genManagerPalettes.mjs` (do not hand-edit
  between the `MG-PALETTES` markers).
- `ManagerThemeProvider` stamps `data-mg-*` attributes on `<html>` and owns
  light/dark resolution (`useManagerTheme()` for the toggle).
- Variable names are shared with the teacher kit on purpose (see
  docs/MANAGER_UI.md → "The one architectural difference") — the Tailwind
  token utilities work in both trees; the `data-mg-*` scoping keeps them apart.
- ⚠️ Never import this kit outside `app/manager/**`, and never import
  `@/components/ui` (teacher) or `@/components/student-ui` inside it.

Full guide + invariants: **docs/MANAGER_UI.md**. Dev gallery:
`/theme-check-manager?palette=wine&mode=dark`.
